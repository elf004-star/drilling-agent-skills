# 领域与输入口径

## 数量、单位与最小区块

井深是沿井身长度：开次/套管顶底深、关键点 `depth_m`、总井深。垂深是竖直投影：地层、钻井液分段、关键点 `verticalDepth_m`。最大垂深与总井深不能互换，关键点显示深度只影响标注。
深度单位 m、真实直径 mm、压力当量密度 g/cm³；井斜角范围 `[0,180)`。井型是标签，几何由井斜角及关键点决定，不擅自改写用户已声明的井型。

| 目标 | 输入块 |
|---|---|
| 地层 | stratigraphy |
| 钻井液 | drillingFluidAndPressure |
| 地层和钻井液 | 两块，最终底深一致 |
| 轨迹（非直井） | wellInfo + keyPoints |
| 井身结构 | wellInfo + keyPoints + holeSections |
| 纯直井结构 | wellInfo（0°）+ holeSections，YAML 可省略 keyPoints |

不要为地层图补一个 0° 占位井；这会触发纯直井必须有开次的校验。区块不可全部缺席。网页文档宣称 wellInfo 必填，但源码支持地层/钻井液独立绘图；网页“最小 YAML”缺少直井开次，不能直接当有效模板。

## YAML 是便利层，JSON 是严格契约

YAML 支持短名、位置式与自动推导，缺席顶层块编译为 null；JSON 不等同 YAML 短写法，须使用服务规范化后的完整字段。优先编辑 YAML，用 `normalize` 查看完整 JSON，不把短写 JSON 发送为 `application/json`。

```yaml
wellInfo:
  示例水平井: 90
keyPoints:
  keypoint: 1000
  A: [1500, 1400]
  B: 2200
holeSections:
  - sec: [2300, 215.9, 裸眼段, auto, slide]
    casings: []
```

这是格式示例，不能作为用户实际井数据。需要明确井底时在短写 wellInfo 中增加 `Depth: 总井深`。
非零井斜角要求 A、B 可得到垂深，且造斜点/侧钻点至少一个存在。短名 `keypoint` 有导眼时为侧钻点，否则为造斜点；两者都有时改用完整字段。
B 点可写单个井深，由 A 点切线推导垂深。完整 YAML 的 B 点 `verticalDepth_m` 可显式写 auto/null：
`垂深_B = 垂深_A + (井深_B - 井深_A) × cos(井斜角)`，保留两位小数。手写数值原样保留，A 点垂深仍须明确。JSON 保持严格数值契约，不把 YAML 自动推导规则复制进客户端。

## 地层与钻井液

地层短写 `地层名: 底深`，底深为垂深、不是厚度，自上而下递增，第一层从 0 起、后层连接前层底深。
钻井液短写 `[底深, 孔隙压力, [窗口下限,窗口上限], 破裂压力?]`，分段底深也是垂深。破裂压力可省略，孔隙压力可为 null。并列两栏最后底深一致，不补齐或截断用户数据。
`fluidDensityAxis: [下限,上限]` 可用 auto；YAML 短写 `drillingFluidLabelHide: [孔隙压力显示?,窗口显示?,破裂压力显示?]` 为显示布尔，不因字段名 hide 反转它的含义。完整契约使用字段名清单，不能混用。

## 开次、套管与固井

`sec: [底深,井径,段名?,绘图井径?,标签模式?]`：开次自浅至深首尾相接。
`cas: [底深,外径,段名?,绘图外径?,构件?]`：套管须在所属开次范围内，外径小于井径。需要尾管顶深/复合套管时从 liner 模板开始，按完整字段或服务支持的位置式表达，勿把上一开次自动当作套管顶端。

- YAML 绘图尺寸用 auto 表示示意环链推导、real 表示真实比例。显式 null 被按 auto 处理并警告；严格 JSON 的 null 含义不同，交给服务编译。
- 真实尺寸用于标注与 CSV，绘图尺寸只控制粗细。不得为改善图形擅改真实直径。
- YAML 套管省略 cement 表示整段固井；none 无固井、full 整段、segments 按区间。用户固井情况不明确时询问，不接受模板默认作为事实。
- 水泥区间端深 auto 跟随图上套管端面，数值是声明井深；备注用声明端深，勿把图上延伸长度当成实测深度。
- 悬挂器位于顶端、套管头位于底端（服务特定术语）；水泥环是另一个事实。段名 null 为通名、空串为不印前缀，均不隐藏段本身。
- `pilotHoleGuideLine: auto` 依赖轨迹和开次，null/省略表示无导眼。

## 图形解释

全图共享深度标尺，地层在场时可能非线性。不要按整图像素高度线性换算垂深或承诺区间裁剪。warnings 表示仍可生成但发生降级，逐条说明被跳过的标注/几何，不把“图成功”解释成输入无问题。
