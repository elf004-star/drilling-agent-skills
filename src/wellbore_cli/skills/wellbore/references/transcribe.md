# 从已有井身结构图转写井数据

用户给图纸或截图，要转成 YAML 再重画时走这里。下面是实际报告里的经验法则；不同报告、图例和标注格式可能不同，**以图例文字和报告实际格式为准**，拿不准就问。

## 取数

**放大着读。** 裁小块放大 4–10 倍分别看：地层栏、曲线栏、套管标注、图例。整图缩略图会吃掉数字。读图用代理自身的图像能力（如 Read 工具）或跨平台脚本；不要依赖 `open`/`start`/`xdg-open` 这类平台命令。

**地层与深度。** 深度栏的数字压在该层名字上方那条界线上，是该层**底深**——直接写 `地层名: 底深`，首层从 0 起。配对按**自上而下的顺序**定，不靠像素位置反推（见 [domain.md](domain.md) 图形解释）。

**曲线分段。** 阶梯线的拐点多数落在地层界线上，此时分段底深直接取该层底深。落在层内的拐点按量出的深度写，YAML 注释里标为测值。

**密度轴。** 用轴线上刻度文字的中心 x 定标：读出两个已知值的刻度位置求线性映射，再从曲线像素位置反算。不从图宽或等间距假设推算。

**套管。** `Φ<mm>mm (<英寸">) × <深度>m` 只给一个深度时，表示从 0 下到该深度；`× (<顶>-<底>)m` 给区间。井径（钻头）与套管尺寸交替出现在同一组标注里，按数值大小与开次配成对，别把钻头当套管。

## 读糊了怎么办

**低分辨率数字用同图其它数字的字符形状比对。** `8`/`0`/`6`、`1`/`7` 在缩略图上常糊成一团；先找一处你确信的同形字符，再对齐着看目标，不靠上下文猜。这一步值一次放大。

**图例配色逐图不同。** 同一颜色在不同图上可能换义（红可能是实钻密度、也可能是孔隙压力）。以图例文字为准，YAML 列位固定 `[底深, 孔隙压力, [窗口下限,窗口上限], 破裂压力?]`。

**接口放不下的东西单独列给用户**，不硬塞进 YAML：独立的「设计密度」影线柱、导眼井身（只画侧钻指引线，不进 `holeSections`）、行内红字标注（如「须家河组顶」）。

## 转写完自检

总井深取全井最大深度——开次底、地层底、关键点里最深的那个；写小了会被 422 挡下。
