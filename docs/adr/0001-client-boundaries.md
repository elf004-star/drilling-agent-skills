# 0001. 标准库 REST 客户端与随包 skill

状态：已采纳。日期：2026-10-04。

为方便跨平台安装，客户端只依赖 Python 3.11 标准库，由 uv tool/pipx/wheel 安装入口 wellbore。领域编译和绘图留在服务端，避免安装重绘图库和维护重复 schema。

易用入口 render 完成预检、提交、等待和下载；jobs/download 等分步入口供自动化和故障恢复。POST 不自动重试，因为公开 REST 没有幂等保证；超时向用户说明结果未知。只暴露 API Key 能执行的公开业务操作，不扩展账户管理范围。

skill 放在 Python 包资源中（`src/wellbore_cli/skills`），由 skill install 复制到目标技能目录。曾用根目录符号链接暴露同一份源码作为短路径，现已移除：Windows 检出时软链接退化为内容是路径文本的普通文件，GitHub ZIP 下载与网页浏览同样无法还原，跨平台行为不一致，而唯一来源本身并不存在漂移问题。分为简短入口、专题参考和有效模板，不生成重复命令封装脚本。

代价：SSE 断线由用户用 wait 恢复，下载中断整份重下，不提供断点/ETag 缓存；skill 安装拒绝覆盖，更新需用户先检查已有版本。将来有真实需求再增加这些能力，不宣称 MCP 能力已在 REST 提供。
